# M7 soak — the induced-outage plan, in seconds from the start of the plan.
#
#   <at_s> <kind> <duration_s> [life_ms]
#
# `cut`   — the loopback port dies: every live connection is RST and new ones get
#           ECONNREFUSED. The error path, and the capped exponential backoff.
# `churn` — connections are relayed normally and closed *cleanly* after `life_ms`, once
#           the handshake and the subscribe frames are long past. This is the branch
#           `reconnect_forever` reads as a clean close.
#
# Lengths are deliberately spread over four orders of magnitude — 0.3 s to 10 minutes —
# because a reconnect loop that only ever sees short breaks is never asked to back off,
# and a `userFills` snapshot only re-teaches a session something after a gap long enough
# for the venue's own state to have moved inside it.
#
# Every gap between outages is at least 45 s of uninterrupted recovery. Hammering
# reconnects is abusive and also measures nothing: what is under test is whether a
# session recovers, and one that is never left alone is never given the chance to fail
# to. The offsets are deliberately not multiples of 20 s (the re-arm cadence) or 15 s
# (the reconcile poll), so successive breaks land at different phases of both.
